# 🩸 LifeDrop — Emergency Blood Donation Ecosystem

LifeDrop is a cross-platform emergency blood donation and requesting platform designed to bridge the critical gap between emergency donation requests and nearby blood donors. 

Built as a full-stack solution featuring a donor-facing mobile application and an administrative management dashboard.

---

## 🚀 Features

### 📱 Mobile App (Donors & Recipients)
- **Real-Time Requests:** Broadcast emergency blood donation requests with required blood types and hospital locations.
- **Donor Matching:** Match donors based on blood compatibility and proximity.
- **Secure Authentication:** Account creation and user verification powered by Firebase Auth.

### 💻 Web Admin Dashboard
- **Request Oversight:** Centralized monitoring of active blood requests and verification status.
- **User Management:** Admin portal to review and manage registered donor profiles.

---

## 🛠 Tech Stack

- **Mobile App:** Flutter, Dart
- **Web Dashboard:** Flutter Web, Dart
- **Backend & Database:** Firebase (Firestore, Cloud Storage, Firebase Auth, Realtime Database)
- **Architecture:** Clean state management, modular component design
