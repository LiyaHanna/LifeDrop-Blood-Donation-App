# 🩸 LifeDrop — Emergency Blood Donation Ecosystem

> 🌐 **Full-Stack Ecosystem:** This repository contains the user-facing mobile application. Looking for the web management portal? Visit the **[LifeDrop Web Admin Dashboard Repository](https://github.com/LiyaHanna/LifeDrop-Admin-Dashboard)**.

LifeDrop is a cross-platform emergency blood donation platform designed to bridge the critical gap between emergency donation requests and nearby compatible donors in real-time. 

Built as a full-stack solution featuring a donor-facing mobile application and a secure web administrative management portal.

---

## 🚀 Key Features

### 📱 Mobile App (Donors & Recipients)
- **Real-Time Requests:** Broadcast emergency blood donation requests with required blood types, urgency levels, and hospital locations.
- **Donor Matching:** Match potential donors based on blood type compatibility and location proximity.
- **Secure Authentication:** User verification, account creation, and profile security powered by Firebase Authentication.

### 💻 Web Admin Dashboard & Security Portal
- **Donor ID & Medical Document Verification:** Administrative workflow to inspect official IDs and health records before granting verified donor status.
- **Blood Type Request Verification:** Dedicated review pipeline to approve user requests for updating blood types based on lab test verification.
- **Emergency Request Oversight:** Centralized real-time monitoring and management of active blood requests across regional hospitals.

---

## 🛠 Tech Stack & Architecture

- **Mobile App:** Flutter, Dart
- **Web Dashboard:** Flutter Web, Dart
- **Backend Services:** Firebase (Cloud Firestore, Firebase Authentication, Cloud Storage, Realtime Database)
